# Veyzen Wallet Bot Terms

This folder is a complete standalone GitHub Pages website.

1. Create a new public GitHub repository, for example `veyzen-terms`.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Use the published URL shown by GitHub as the Terms of Service URL in Discord.

Only `index.html` and `.nojekyll` are needed by GitHub Pages. The README is only instructions.
